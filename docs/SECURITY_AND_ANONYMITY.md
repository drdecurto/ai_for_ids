# Security and anonymity

This package is intended for double-blind review.

- No API keys, access tokens, cookies, or credential files are included.
- No raw benchmark captures are redistributed.
- The anonymous package contains no author names, institutional email addresses, personal home paths, public non-anonymous repository URL, or Git history.
- Potentially identifying antecedent citations are masked in the blind manuscript rather than encoded in this repository.
- Hosted-model raw generations contain prompts, labels, model outputs, timing, and cost metadata only; they do not contain endpoint credentials.
- The completed final-revision notebook was sanitised before release: outputs and execution counts were cleared, the identifiable development repository URL was removed, and credentials are read only from environment variables or notebook secret stores.
- Re-execution notebooks do not print secrets.
